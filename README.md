# <img src="icons/title.png" width="90"> 초등 필수 영단어 800

귀여운 고양이와 함께 공부하는 **초등 필수 영단어 800** PWA입니다.

📱 휴대폰 설치 가능  
🌐 인터넷 없이 사용 가능 (PWA)  
🔊 영어 발음 지원  
🎮 재미있는 퀴즈 학습  
💾 백업 및 복원 지원

---

## ✨ 주요 기능

- 📖 초등 필수 영단어 800개
- 🔍 단어 검색
- 🔠 A~Z 알파벳 검색
- ✅ 외운 단어 체크
- 📊 학습 진행률
- 🎯 오늘 목표 설정
- 🔥 연속 학습 기록
- 🔊 영어 발음 듣기
- 📝 오답노트
- 🎮 4가지 퀴즈
  - 영어 → 뜻
  - 뜻 → 영어
  - 듣기
  - 철자 쓰기
- 🎆 정답 폭죽 효과
- 🌧 오답 비 효과
- 💾 백업 / 복원
- 🔐 라이선스 인증

---

## 📱 PWA 설치

Android

Chrome 또는 삼성 인터넷에서

메뉴 →

**홈 화면에 추가**

또는

**앱 설치**

를 누르면 앱처럼 사용할 수 있습니다.
