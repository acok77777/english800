# 🐱 초등 필수 영단어 800

귀여운 고양이와 함께 공부하는  
초등 필수 영단어 800 PWA 학습 앱입니다.

## 📱 주요 기능

- 📚 초등 필수 영단어 800개 학습
- 🔍 영어 / 뜻 / 발음 검색
- 🔤 A~Z 알파벳 검색
- ✅ 외운 단어 체크 기능
- 📊 학습 달성률 확인
- 🎯 오늘의 목표 단어 설정
- 🔊 영어 발음 듣기 지원

## 🎮 퀴즈 학습

- 1️⃣ 단어의 뜻 맞추기
- 2️⃣ 단어의 스펠링 맞추기

퀴즈 기능:

- 체크한 단어만 출제
- 랜덤 문제 출제
- 문제별 점수 기록
- 다시 풀기 지원
- 날짜별 퀴즈 누적 기록

## 💾 데이터 관리

- 백업 및 복원 지원
- 학습 기록 저장
- 퀴즈 점수 저장

## 🌐 PWA 지원

- 📱 휴대폰 설치 가능
- 🌐 인터넷 없이 사용 가능
- ⚡ 빠른 실행 지원

## 🐱 만든 이유

초등학생이 재미있게 영어 단어를 외우고  
스스로 학습 습관을 만들 수 있도록 제작한  
영단어 학습 PWA입니다.
