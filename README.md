# 📚 초등 필수 영단어 800 PWA

초등학생 영어 학습을 위한 **필수 영단어 800개 학습 웹앱(PWA)** 입니다.

웹사이트처럼 실행할 수 있고, 스마트폰에서는 앱처럼 설치하여 사용할 수 있습니다.

---

## ✨ 주요 기능

### 📖 단어 학습

- 초등 필수 영어 단어 800개 제공
- 영어 단어
- 한글 발음
- 뜻 표시
- 원어민 발음 듣기 기능
- A~Z 알파벳별 단어 검색
- 단어 검색 기능

---

## ✅ 학습 관리

- 외운 단어 체크
- 안 외운 단어 보기
- 학습 진행률 표시
- 오늘 목표 단어 설정
- 연속 학습 일수 표시
