# 🐱 초등 필수 영단어 800

초등학생을 위한 **PWA(Progressive Web App)** 영어 단어 학습 앱입니다.

홈 화면에 설치하여 인터넷 없이도 사용할 수 있습니다.

---

# ✨ 주요 기능

## 📖 단어장

- 전체 단어 보기
- A ~ Z 분류
- 영어/뜻 검색
- 즐겨찾기 ⭐
- 체크한 단어
- 외운 단어 보기
- 안 외운 단어 보기
- 오늘의 20단어
- 랜덤 20단어

---

## 🔊 발음

- 미국식 발음
- 영국식 발음
- 발음 속도 조절
- 모바일 지원

---

## 📝 퀴즈

### ① 영어 → 뜻

### ② 뜻 → 영어

### ③ 발음 듣고 단어 맞추기

### ④ 철자 쓰기

---

## 🎯 퀴즈 기능

- 랜덤 출제
- 힌트

- 오답노트
- 다시 풀기
- 최고 점수 저장

---

## 📊 학습 현황

- 학습 진도
- 진행률
- 진행바
- 외운 단어 개수
- 남은 단어 개수
- 오늘 학습 개수

## 📅 학습 달력

- 학습한 날짜 표시
- 월별 달력
- 학습일 수

---

## 💾 백업

- JSON 백업

- LocalStorage 저장

---

## 🔐 라이선스

- 첫 실행 라이선스 인증
- 오프라인 인증
- 구매자 전용 사용
